## 3. 실행 10초·버튼 2초 확인 (측정 완료, M4 통과와 함께 기록)
| 항목 | 결과 |
|---|---|
| 앱 실행, 릴리스 빌드, 강제 종료 후 3회 | 2.6 / 1.7 / 1.6초 (기준 10초 통과) |
| 앱 실행, 디버그 빌드 (참고) | 10.3~12.2초 (Compose 디버그 + 내장 그래픽). 제출은 릴리스 기준 |
| "이야기 시작" 탭 → 음성 시작 | 0.28~0.65초 (기준 2초 통과) |
| "이야기 잠시 멈추기" 탭 → 음성 중지 | 0.28~0.38초 |

- 측정 방법: 시스템 로그 `Displayed` 시간, 버튼은 탭 시각부터 `onStart`·`onStop` 로그까지 (adb 탭 지연 약 0.25초 포함)
- 측정용 릴리스 APK는 PC의 디버그 키로 서명했다(저장소 변경 없음). 지금 에뮬레이터에는 이 릴리스 빌드가 설치되어 있다.
- 실행 직후 TTS 준비까지 3.5~8초 걸린다. 그 사이 "이야기 시작"을 누르면 재생되지 않으므로 M5에서 음성 준비 전에는 버튼을 비활성화한다.

## 4. 디버그 표시 숨김 (구현됨, M4 확인에 포함)
- "신호 지원 상태"와 "최근 원시 신호"는 기본으로 숨김. 앱 이름을 길게 누르면 켜고 끈다.
- 녹화 전에 꺼져 있는지 확인한다.

## 5. 타이머 침묵 재검토 (녹화 때)
- 늦은 onDone이 간헐적으로 생긴다. M3 재시험에서 7문장 중 3번은 예상 시간 타이머로 끝났고, 음성이 끝난 뒤 4~6초 침묵이 있었다.
- 타이머 배율(글자 수 × 0.25초 × 1.5 + 2초)은 사용자 결정으로 유지 중. 60초 녹화에서 침묵이 거슬리면 배율 조정을 다시 검토한다.
